### Tugas 2
1. Proyek portofolio/urls.py menerima permintaan dari browser, lalu meneruskannya ke main.urls lewat include("main.urls"). Aplikasi main/urls.py menemukan pola URL lalu mencocokkan permintaan, contohnya skill dicocokan dengan path("skill/", show_skill, name="show_skill"), lalu memanggil fungsi view show_skill. View main/views.py:show_skill lalu mengambil data dari database lewat query Skill.objects.all() (ambil semua objek model Skill), kemudian memasukkannya ke dictionary context sebagai skill_list, lalu memanggil render(request, "skill.html", context). Setelah itu, data model skill pada models.py diambil. Kemudian template menerima context, lalu {% for skill in skill_list %} menampilkan tiap objek jadi HTML. Kalau list kosong, {% empty %} menampilkan pesan "Belum ada skill yang ditambahkan." Setelahnya, browser menerima HTML yang sudah jadi dan me-render-nya.
2. Agar mudah untuk digunakan secara berulang dan lebih simpel untuk pemeliharaan dan pengembangan aplikasi. Selain itu, pengembangan juga menjadi lebih efisien karena developer tidak perlu mengedit langsung di template tiap ada pergantian data pada model.

Makemigrations berfungsi untuk mendeteksi perubahan pada models.py dan membuat file migrasi baru di dalam folder migrations, sedangkan migration berfungsi untuk membaca file migrasi yang ada dan mengeksekusi perintah SQL ke database.
